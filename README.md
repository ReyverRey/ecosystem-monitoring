# Мониторинг экосистемы

Система мониторинга и прогноза качества воздуха по городам Беларуси (курсовая работа, МГЭИ им. А.Д. Сахарова БГУ).

## Запуск

```bash
pip install -r requirements.txt
python src/clean/parse_belstat_a2.py     # воздух: xlsx -> tidy CSV
python src/clean/parse_belstat_seis.py   # вода и отходы: xlsx -> tidy CSV
python src/eda/eda_analysis.py           # EDA: графики и таблицы в reports/
python src/models/train_forecast.py      # модели прогноза -> метрики и прогноз 2026-2028
streamlit run app/app.py                 # дашборд
```

Все данные лежат в `data/` и не требуют сети (по ТЗ).

## Структура

- `data/raw` — исходные выгрузки Белстата (SEIS); `data/processed` — tidy-датасеты с указанием файла-источника у каждого значения
- `src/clean` — конвейер извлечения, `src/eda` — разведочный анализ, `src/models` — прогноз
- `app/` — дашборд Streamlit (Обзор, Машина времени, Динамика, Прогноз, О данных)
- `reports/` — выводы EDA и моделей, метрики, графики
- `tests/` — smoke-тест дашборда (`python tests/test_app_smoke.py`)

## Источники данных

Белстат, Совместная система экологической информации: A.2 (воздух, 2005–2025, 12 городов),
I.1 (отходы), C.1/C.3/C.11/C.16 (вода). Лицензия: открытые данные, ссылка на источник обязательна.
